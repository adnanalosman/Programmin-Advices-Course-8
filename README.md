# Algorithms & Problem Solving – Level 4 (C++)

This repository contains my practice solutions for the course **Algorithms & Problem Solving – Level 4**, taught by Dr. Mohammed Abu-Hadhoud on the Programming Advices platform.

## About the Course

The course is the fourth level in the Algorithms & Problem Solving series and is written in C++. It consists of:

- 65 programming problems, ranging from basic to more advanced.
- Two final projects: Bank Extension 2 and ATM System.

## Purpose of This Repository

This project is a personal exercise to practice what I learned in the course. It is not an official representation of the course or of the Programming Advices platform.
